- 🎨 Современный дизайн с градиентами и анимациями
- 📱 Полностью адаптивная верстка для всех устройств
- ⚡ Плавные анимации и переходы
- 🚀 Быстрая загрузка и оптимизированная производительность
- 📧 Функциональная контактная форма с валидацией
- 🌟 Интерактивные элементы и hover-эффекты

## Установка и запуск

### Вариант 1: Простой запуск
1. Откройте файл `index.html` в любом современном веб-браузере
2. Страница готова к использованию!

### Вариант 2: Локальный сервер (рекомендуется)
Для лучшей работы рекомендуется использовать локальный сервер:

```bash
# С помощью Python 3
python -m http.server 8000

# С помощью Python 2
python -m SimpleHTTPServer 8000

# С помощью Node.js (если установлен npx)
npx serve .

# С помощью PHP
php -S localhost:8000
```

Затем откройте браузер и перейдите по адресу `http://localhost:8000`

## Технические детали

### CSS Features
- CSS Grid и Flexbox для адаптивной верстки
- CSS Custom Properties (переменные) для управления темой
- Современные CSS-анимации и трансформации
- Media queries для мобильной адаптивности
- Backdrop-filter для эффекта размытия

### JavaScript Features
- Плавная прокрутка между секциями
- Мобильное меню с анимацией
- Скрытие/показ навигации при прокрутке
- Валидация форм с уведомлениями
- Анимация счетчиков статистики
- Parallax эффекты
- Lazy loading анимации

### Адаптивность
- Мобильные устройства: < 480px
- Планшеты: 480px - 768px
- Десктоп: > 768px

## Кастомизация

### Цвета
Основные цвета настраиваются через CSS переменные в `:root`:

```css
:root {
    --primary-color: #2563eb;
    --secondary-color: #1e40af;
    --text-primary: #1f2937;
    /* ... другие переменные */
}
```

### Контент
- Замените текстовое содержимое в `index.html`
- Обновите мета-теги в `<head>`
- Добавьте свои изображения в папку `images/`

### Стили
- Основные стили находятся в `styles.css`
- Используйте CSS переменные для единообразия
- Медиа-запросы уже настроены для адаптивности
